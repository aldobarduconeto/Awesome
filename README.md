# Awesome

**Leveza. Usabilidade. Privacidade.**

Landing page oficial da Awesome, um ecossistema de aplicativos desenvolvidos para simplificar o dia a dia, com foco em desempenho, facilidade de uso e respeito à privacidade do usuário.

## ✨ Sobre

A Awesome acredita que bons aplicativos devem ser simples, eficientes e respeitar os dados de quem os utiliza.

Nosso objetivo é desenvolver ferramentas que ofereçam uma experiência intuitiva, sem complexidade desnecessária, contas online obrigatórias ou coleta desnecessária de dados pessoais.

## 🚀 Projetos

- **[AwesomeSafe](https://github.com/aldobarduconeto/AwesomeSafe)** — Proteção de arquivos com foco em segurança e simplicidade.
- **[AwesomeOrin](https://github.com/aldobarduconeto/AwesomeOrin)** — Aplicativo desenvolvido com foco em uma experiência moderna e prática.
- **[FeedFlow](https://github.com/aldobarduconeto/FeedFlow)** — Leitor de feeds para acompanhar e organizar conteúdos.

## 🎨 Tecnologias

A landing page foi desenvolvida utilizando:

- HTML5
- CSS3
- JavaScript

Sem frameworks ou dependências externas obrigatórias.

## 🔒 Nossa filosofia

- **Leveza:** software eficiente, sem excessos desnecessários.
- **Usabilidade:** interfaces intuitivas e experiências simples.
- **Privacidade:** respeito aos dados pessoais e sem exigência de contas online quando desnecessárias.
